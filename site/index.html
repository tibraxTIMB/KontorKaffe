Personvern og medlemskap

KontorKaffe er ein privat, frivillig kaffiklubb, ikkje ei kommunal teneste. Baristaen handterer medlemsnummer, valfritt kallenamn, klipp, bestilling og sikringsnøklar for kort og nettlesar. Opplysningane kan knytast til deg og vert brukte berre til medlemskap og bestillingar. GitHub Pages leverer nettsida, og Supabase driftar databasen i Frankfurt. Leverandørane kan handsama tekniske loggar, mellom anna IP-adresser. Appen har ikkje reklame, analyseverktøy, kundekonto eller kundevarsling. Ein nødvendig lokal nettlesarnøkkel vert lagra for å sikra kortet. Avslutta bestillingar vert normalt sletta etter 24 timar; medlemsdata vert lagra til medlemskapet vert sletta. Tekniske loggar og eventuelle sikkerheitskopiar kan ha andre lagringstider. Kontakt baristaen personleg for innsyn, retting, sletting eller spørsmål; du kan òg sletta lokal nettlesarlagring. Sletting av medlemskap gjer QR-kortet ugyldig.
