# KontorKaffe 2.7 – no Firebase
Open bar, start appvarsling under Drift, allow Android notifications. A visible dataSync foreground service checks every 15 seconds. It uses a limited six-hour opaque session, not the admin password or JWT; server returns only pending order IDs and mode. One active monitoring session; starting a new one invalidates the old. Stop action, logout or closing the bar stops monitoring. Android 15 restricts dataSync foreground services to six hours of background time per rolling day; local service stops at 5h55. Force stop, reboot, battery restrictions, lack of network or OS termination can stop delivery. No guaranteed delivery. Test on the actual phone with screen locked, app swiped away and network loss; normal browser push is separate. No third-party SDK or new account. Production APK remains test signed.
