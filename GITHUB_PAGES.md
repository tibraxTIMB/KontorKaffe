# Dedicated GitHub Pages for KontorKaffe
The existing tibraxtimb.github.io/KontorKaffe/ URL must remain a credential-free preview because it shares an origin with other repositories. Do not relax this restriction.
Use a free new organization whose name is kontorkaffe or kontorkaffe-<suffix>. Create a public repository named exactly <organization>.github.io. Keep this organization exclusively for KontorKaffe; do not add other projects. The source repo remains tibraxTIMB/KontorKaffe. Copy only the contents of the isolated site package to the root of the new repository, including .nojekyll; choose main / root under Settings → Pages. Alternatively transfer the KontorKaffe repository and rename it <organization>.github.io, then enable GitHub Actions as Pages source; the workflow checks the dedicated owner and root URL automatically.
Once the site is verified on HTTPS, log into Barista and enter its exact root URL under Drift. The server validates the project marker before locking the hostname and generating push keys. The sample organization name is not a claim that it exists. Administrator setup still requires one explicitly authorized account. Members do not register.
